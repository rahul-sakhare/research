# Visual Chronicle Image Directory

Place conference podium, poster session, invited talk, and field milestone photographs here.

### Recommended format:
- Format: `.jpg`, `.jpeg`, `.png`, or `.webp`
- Resolution: 1200px to 1920px wide
- Naming convention: `YYYY_event_shortname.jpg` (e.g., `2026_trb_podium.jpg`, `2025_purdue_roadschool.jpg`)

After placing an image here, reference its path in `research/gallery-data.js`:
```javascript
image: "assets/img/gallery/2026_trb_podium.jpg"
```
